## 🎯 간단한 로또 게임 - 기능 요구사항

### 📌 주요 목표
사용자는 로또를 구입하고, 당첨 번호 및 보너스 번호를 입력한다.  
모든 로또의 당첨 결과를 계산한 뒤, **등수별 당첨 개수와 총 수익률을 출력한다.**

---

## 🧩 기능 목록

### 1️⃣ 입력 기능

#### 💰 구입 금액 입력
- 사용자로부터 **로또 구입 금액**을 입력받는다.
- 구입 금액은 **1000원 단위의 양의 정수**여야 한다.
- 잘못된 입력 시 `Error`를 발생시키고 재입력을 요구한다.
- 입력은 `MissionUtils.Console.readLine()` 사용.

예시:  
구입금액을 입력해 주세요.
5000

#### 🎟️ 당첨 번호 입력
- 지난 주 **당첨 번호 6개**를 입력받는다.
- 번호는 쉼표(`,`)로 구분된 형태로 입력받는다.
- 중복된 숫자 또는 1~45 범위를 벗어난 숫자가 포함되면 `Error` 발생.

예시:  
당첨 번호를 입력해 주세요.
1,2,3,4,5,6

#### 🔢 보너스 번호 입력
- **보너스 번호 1개**를 추가로 입력받는다.
- 당첨 번호와 중복될 수 없으며, 1~45 범위의 정수여야 한다.
- 잘못된 값 입력 시 `Error` 발생.

예시:  
보너스 번호를 입력해 주세요.
7

---

### 2️⃣ 로또 발행 기능

#### 🧾 로또 자동 발행
- 입력된 금액을 기준으로 **금액 / 1000** 개수만큼 로또를 자동으로 생성한다.
- 각 로또는 **1~45 사이의 중복 없는 6개의 숫자**로 구성된다.
- 숫자는 **오름차순 정렬된 형태로 출력**된다.
- 로또 번호 생성은 `MissionUtils.Randoms.pickUniqueNumbersInRange(1, 45, 6)` 사용.

예시:  
5개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
...

---

### 3️⃣ 당첨 결과 계산 기능

#### 🏆 당첨 조건 판별
- 각 로또의 번호를 기준으로 **당첨 번호 및 보너스 번호 일치 개수**를 계산한다.
- 일치 개수에 따라 아래 기준으로 등수를 판정한다.

| 등수 | 조건 | 상금 |
|:--:|:--|:--:|
| 1등 | 6개 번호 일치 | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 |
| 3등 | 5개 번호 일치 | 1,500,000원 |
| 4등 | 4개 번호 일치 | 50,000원 |
| 5등 | 3개 번호 일치 | 5,000원 |

---

### 4️⃣ 결과 출력 기능

#### 📊 당첨 통계 출력
- 각 등수별 당첨 개수를 출력한다.

예시:  
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개

#### 💸 수익률 출력
- 당첨 내역을 기반으로 **총 상금 합계**를 계산한다.
- 총 상금 / 구입 금액 × 100으로 **수익률(%)**을 구한다.
- 소수점 둘째 자리까지 반올림하여 출력한다.

예시:  
총 수익률은 62.5%입니다.

---

### 5️⃣ 예외 처리

#### ⚠️ 잘못된 입력값 검증
다음과 같은 경우 `Error` 발생 후 프로그램 재실행 또는 종료:
- 구입 금액이 **1000원 단위가 아닌 경우**
- 구입 금액이 **0 이하이거나 숫자가 아닌 경우**
- 당첨 번호가 **6개가 아닌 경우**
- 당첨 번호 또는 보너스 번호가 **1~45 범위를 벗어난 경우**
- 당첨 번호와 보너스 번호가 **중복된 경우**

🚫 `process.exit()` 호출은 금지한다.

---

### 6️⃣ 테스트 기능

#### 🧪 테스트 범위
- **랜덤 번호 제어 테스트**
    - `Randoms.pickUniqueNumbersInRange` 모킹(mock)으로 예측 가능한 로또 생성 테스트
- **입력 검증 테스트**
    - 유효하지 않은 입력 시 예외 발생 여부 확인
- **당첨 판별 테스트**
    - 당첨 번호 조합에 따른 정확한 등수 계산 확인
- **수익률 계산 테스트**
    - 총 상금과 구입 금액으로 계산된 수익률 검증
